# Арсенал разума

Личный цифровой сайт для хранения принципов, мышления, дисциплины, целей, ошибок и знаний.

## Описание

Этот репозиторий служит хранилищем для личного развития и самосовершенствования. Здесь собираются:

- **Принципы** — ключевые жизненные убеждения
- **Мышление** — методы и подходы к решению проблем
- **Дисциплина** — системы и привычки для саморазвития
- **Цели** — краткосрочные и долгосрочные задачи
- **Ошибки** — уроки, извлечённые из ошибок
- **Знания** — накопленная информация и опыт

## Структура проекта

```
arsenal-razuma/
├── principles/      # Принципы и убеждения
├── thinking/        # Методы мышления
├── discipline/      # Системы дисциплины
├── goals/           # Цели и задачи
├── mistakes/        # Уроки из ошибок
├── knowledge/       # Хранилище знаний
└── README.md        # Этот файл
```

## Как использовать

Этот репозиторий — это личный инструмент для отслеживания роста и развития. Используйте его как вам удобно: для фиксирования идей, планирования, анализа прогресса.

## Лицензия

Этот проект открыт для личного использования.
